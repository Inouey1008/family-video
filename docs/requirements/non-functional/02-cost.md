# Cost

| # | 要件 |
|---|---|
| NFR-09 | 固定費は月額ほぼ 0 円にする (配信・データ管理・認証・処理は無料枠に収める) |
| NFR-10 | 古くなって見られなくなった動画は、保存費用が自動で下がる |
| NFR-11 | 月額の費用が予算の 80% に達したら通知する |
| NFR-12 | 完了しなかったアップロードの残骸は、7 日後に自動で削除する |

## Storage Cost Estimate

保存料の目安 (保存した動画が長く見られないと、費用が自動で下がる前提):

| 保存量 | 月額 (すべて最近見られている場合) | 月額 (ほぼすべて古い場合) |
|---|---|---|
| 100 GB | 約 $2.5 | 約 $0.5 |
| 500 GB | 約 $12.5 | 約 $2.5 |
| 1 TB | 約 $25.6 | 約 $5.1 |

> 単価は 2026 年 11 月時点で調べた値です。採用前に料金を再確認すること。
