# Security

| # | 要件 |
|---|---|
| NFR-01 | 動画とサムネイルは、ログインした家族しか取得できない。取得の許可は短時間で失効する |
| NFR-02 | アップロードできるのは、ログインした家族だけにする。保存先は利用者が決められず、サービス側が決める。アップロードの許可は短時間で失効する |
| NFR-03 | 他のサイトなどから、家族本人の意図しない操作を送り込まれても受け付けない。ログインの資格情報は、画面のスクリプトから読み取れないようにする。ログインの応答のすり替えや横取りを受け付けない |
| NFR-04 | 利用者がどこまで操作できるかの判定は、利用者の端末ではなくサービス側で行う |
| NFR-05 | 外部のサイトのスクリプトは読み込まない。通信は常に暗号化し、ブラウザ側の防御機能も有効にする |
| NFR-06 | 各部品には、必要最小限の権限だけを与える。長期間有効な認証情報は発行しない |
| NFR-07 | 利用回数の制限、不正アクセス対策、地域制限で、乱用と課金の暴走を防ぐ (詳細は [4.7](07-abuse-protection.md)) |
| NFR-08 | クラウドの最上位アカウントには多要素認証を設定し、普段は使わない |
