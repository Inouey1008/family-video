# Operations

| # | 要件 |
|---|---|
| NFR-150 | 環境は `dev` と `prod` の 2つだけにする (staging は作らない)。どちらも同じ Terraform のコードから作り、違いは変数 (ドメイン、地域制限、ログレベルなど) だけにする |
| NFR-151 | Lambda はバージョンとエイリアスで管理し、デプロイに失敗したら前のバージョンに戻せるようにする |
| NFR-152 | DB のマイグレーションは、前のバージョンのコードでも動く形 (列の追加を先に行うなど) で進める |
| NFR-153 | Runbook を用意する: 家族の追加と削除 (開発者が AWS 側で行う)、アカウントの復旧 ([FR-05](../functional.md#31-authentication-and-members)。開発者が AWS 側で行う)、障害対応、署名用の鍵とカスタムヘッダーの入れ替え、S3 のバージョニングからの復元 |
