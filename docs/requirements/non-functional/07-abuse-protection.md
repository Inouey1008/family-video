# Abuse Protection

## Rate Limiting

| # | 要件 |
|---|---|
| NFR-35 | ログインの総当たりを防ぐ。パスワードで 5 回失敗すると短時間ロックされ、以降は失敗するたびにロック時間が倍になり、最大約 15 分になる |
| NFR-36 | サービス全体のリクエスト数に上限を付け、負荷の高い操作にはさらに厳しい上限を付ける |
| NFR-37 | アップロードの本数と容量には上限を設けない ([FR-11](../functional.md#32-upload))。保存量の増加と費用は、費用の通知 ([NFR-11](02-cost.md)) と保存量の指標で把握する |
| NFR-38 | 利用者の端末からのエラー送信は、回数と 1 回あたりのサイズに上限を付ける |
| NFR-39 | 上限を超えたときは、時間をおいて再試行するよう画面に表示する |
| NFR-40 | 同時に処理する数に全体の上限を付ける |

設定値の例 (運用しながら調整する):

| 対象 | 制限 |
|---|---|
| サービス全体 | 20 リクエスト/秒、瞬間的には 40 |
| アップロードの開始 | 2 リクエスト/秒、瞬間的には 5 |
| 端末からのエラー送信 | 1 リクエスト/秒、瞬間的には 3 |
| 同時に処理する数 | 10 |

## Bot Protection

| # | 要件 |
|---|---|
| NFR-41 | ログインしていない人が見られるのは、ログイン画面と画面の部品だけにする。それ以外はログイン画面へ誘導し、保存データには触れない |
| NFR-42 | 検索エンジンに載らないようにする |
| NFR-43 | 公開するコードには、ドメインや配信元の URL などの環境固有の値を書かない |

## Geo Restriction

| # | 要件 |
|---|---|
| NFR-44 | 日本国内からのアクセスだけを許可する (追加料金なし) |
| NFR-45 | 別の入り口から直接アクセスされても、地域制限を回避されないようにする |
| NFR-46 | 家族が海外へ旅行するときは、一時的に旅行先の国を許可できる |
| NFR-47 | 通信を中継する iPhone のプライバシー機能を使っていても、日本からのアクセスと判定されるかを、リリース前に確認する |
