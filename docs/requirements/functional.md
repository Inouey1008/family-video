# Functional Requirements

## 3.1 Authentication and Members

| # | 要件 |
|---|---|
| FR-01 | 開発者が家族を招待してアカウントを作る。自己登録はできない |
| FR-02 | パスワードを覚えなくてもログインできる。予備として、パスワードと追加の確認によるログインも使える |
| FR-03 | 一度ログインすれば、毎回ログインし直さなくても使い続けられる |
| FR-04 | 役割は分けず、家族は全員が同じ権限を持つ。誰でもどの動画も削除でき、削除した動画は 30 日間は復元できる ([FR-18](#34-deletion)) |
| FR-05 | ログインに使っていた端末をなくした家族のアカウントを、開発者が手順書に沿って復旧できる。開発者自身が締め出されたときの復旧手段も用意する |

## 3.2 Upload

| # | 要件 |
|---|---|
| FR-06 | 動画を複数まとめて選んでアップロードできる |
| FR-07 | 通信が途切れても、大きな動画を最初から送り直さずにアップロードできる |
| FR-08 | 途中で中断しても、続きから再開できる |
| FR-09 | 動画ごとに進捗と状態 (待機中・送信中・完了・失敗) を表示する。失敗した動画だけを再送できる |
| FR-10 | サムネイルと再生時間は、利用者が入力しなくても自動で付く |
| FR-11 | 1 本あたりのファイルサイズにも、利用者ごとの本数・容量にも上限は設けない。完了時には、送ろうとしたサイズと実際に保存されたサイズが一致するかだけを確認する |
| FR-12 | 動画は圧縮・変換せず、元の形式のまま保存する |

## 3.3 Listing, Playback and Download

| # | 要件 |
|---|---|
| FR-13 | 動画の一覧をサムネイル付きで、撮影日の新しい順に表示する |
| FR-14 | 動画が増えても、一覧を少しずつ読み込んで表示できる |
| FR-15 | 動画をブラウザで再生できる。再生位置を途中に移すこともできる |
| FR-16 | 再生を始めるときに、利用者が再読み込みなどの操作をしなくても再生できる |
| FR-17 | 家族は誰でも、動画を元のファイルのまま (圧縮・変換せずに) 自分の端末に保存できる |

## 3.4 Deletion

| # | 要件 |
|---|---|
| FR-18 | 誤って削除しても、30 日間は復元できる。30 日を過ぎた動画は完全に削除する |

## 3.5 Home Screen

| # | 要件 |
|---|---|
| FR-19 | ホーム画面から、アプリのように起動できる |

## 3.6 Migration and Export

| # | 要件 |
|---|---|
| FR-20 | LINE などにある既存の動画は、リリース後に各自が必要な分だけ、複数アップロード ([FR-06](#32-upload)) で移す。一括取り込みの手順は作らず、移行の期限も設けない |
| FR-21 | 元の動画とその情報 (撮影日時など) を、開発者が一括で取り出せる。手順は手順書に書く。将来ほかのサービスに移るときのため |
