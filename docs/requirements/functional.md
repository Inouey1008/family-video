# Functional Requirements

## 3.1 Authentication and Members

| # | 要件 |
|---|---|
| FR-01 | 開発者が AWS 側で家族を招待してアカウントを作る。自己サインアップはできない |
| FR-02 | パスキーでログインする。予備としてパスワードと TOTP の多要素認証も使える |
| FR-03 | ログイン状態は HttpOnly Cookie で保持する |
| FR-04 | 役割は分けず、家族は全員が同じ権限を持つ。誰でもどの動画も削除でき、削除した動画は 30 日間は復元できる ([FR-30](#34-deletion)) |
| FR-05 | パスキーを登録した端末をなくした家族のアカウントを、開発者が AWS 側で Runbook に沿って復旧する (パスキーの再登録を可能にする)。開発者自身が締め出されたときの復旧手段も用意する |

## 3.2 Upload

| # | 要件 |
|---|---|
| FR-10 | 動画を複数まとめて選んでアップロードできる |
| FR-11 | 大きな動画は分割して並列でアップロードする (S3 マルチパート) |
| FR-12 | 途中で中断しても、続きから再開できる |
| FR-13 | 動画ごとに進捗と状態 (待機中・送信中・完了・失敗) を表示する。失敗した動画だけを再送できる |
| FR-14 | サムネイルと再生時間は端末側で生成・取得する |
| FR-15 | 1本あたりのファイルサイズにも、利用者ごとの本数・容量にも上限は設けない。完了時には、申告されたサイズと実際にアップロードされたサイズが一致するかだけを確認する |
| FR-16 | 動画は圧縮・変換せず、元の形式のまま保存する |

## 3.3 Listing and Playback

| # | 要件 |
|---|---|
| FR-20 | 動画の一覧をサムネイル付きで、撮影日の新しい順に表示する |
| FR-21 | 一覧はページングまたは無限スクロールで表示する |
| FR-22 | 動画をブラウザで再生できる。シーク (Range リクエスト) にも対応する |
| FR-23 | 再生用の URL は期限付きにし、期限が切れたら取り直す |

## 3.4 Deletion

| # | 要件 |
|---|---|
| FR-30 | 削除は論理削除にする。誤って削除しても、30 日間は復元できる。30 日を過ぎた動画は完全に削除する |

## 3.5 PWA

| # | 要件 |
|---|---|
| FR-40 | ホーム画面に追加して、アプリのように起動できる |
| FR-41 | Service Worker がキャッシュするのは画面の部品だけにする。動画はキャッシュしない |

## 3.6 Migration and Export

| # | 要件 |
|---|---|
| FR-50 | LINE などにある既存の動画は、リリース後に各自が必要な分だけ、複数アップロード ([FR-10](#32-upload)) で移す。一括取り込みの手順は作らず、移行の期限も設けない |
| FR-51 | 元の動画とメタデータを一括で取り出せる (開発者が S3 と DB から取り出す手順を Runbook に書く)。将来ほかのサービスに移るときのため |
