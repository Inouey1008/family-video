# family-video PRD

家族の動画を、容量を気にせず共有するためのアプリの要件。

## Problem

- 動画を無料でアップロードできるサービスは、一定の容量を超えると課金される。
- これまで家族の動画は LINE で共有していたが、有料化された。
- 容量の上限と費用を気にして、動画を残すこと自体をためらう状況になっている。

## Users

- 家族: 全員が iPhone を使う。スマホに慣れていない人もいる。
- 開発者: 家族の招待、アカウントの復旧、動画の一括取り出しを行う。

## Goals

- 容量を気にせず、家族の動画をどんどんアップロードして共有できる。
- 費用は、保存量に比例する分だけにする (固定費はほぼ 0 円)。
- 招待した家族だけが動画を見られる。
- 保守の手間を小さく保つ。
- 個人開発の成果物として公開できる。

## Non-Goals

- 動画の変換・圧縮 (サービス側・アップロード前の端末側とも)。必要になったら後から追加する。
- オフラインでの閲覧。初期リリースの範囲を絞るため。
- アルバム・コメント機能。後から追加して対応する。

## User Stories

家族として:

- 複数の動画をまとめてアップロードしたい。大きな動画でも、通信が途切れたり中断したりしたときに、最初から送り直さず続きから再開したい。
- 動画を、サムネイルと再生時間付きの一覧で見たい。
- 一覧は月ごと・年ごとの表示を切り替えて、見たい月・年を選びたい。最初は今月 (年ごとなら今年) を表示したい。
- 選んだ月・年の中では、撮影日の古い順に並べたい。動画が多くても、少しずつ読み込んで見られるようにしたい。
- 動画をそのまま再生し、見たい位置へ移りたい。
- 動画を元のファイルのまま (圧縮・変換せずに) 自分の端末に保存したい。
- 好きな動画をお気に入りにしたい。お気に入りは自分だけのもので、ほかの家族のお気に入りには影響しない。
- お気に入りの動画だけを絞り込んで、一覧で見たい。
- 誤って削除しても、30 日以内なら元に戻したい。
- ホーム画面から、アプリのように起動したい。
- パスワードを覚えなくてもログインしたい。

開発者として:

- 家族を招待してアカウントを作りたい。自己登録はできないようにしたい。
- ログインに使っていた端末をなくした家族のアカウントを、手順書に沿って復旧したい。
- 将来ほかのサービスに移るときのために、元の動画とその情報を一括で取り出したい。

## Quality

- Security: 動画は、ログインした家族しか取得できない。家族だけが使うアプリでも、不正アクセス・乱用・課金の暴走を防ぐ対策を入れる。日本国内からのアクセスだけを許可する。
- Cost: 固定費はほぼ 0 円にする。古くなって見られなくなった動画は、保存費用が自動で下がるようにする。月額の費用が予算に近づいたら通知する。
- Maintenance: 利用する外部の部品は最小限にし、更新と脆弱性を定期的に確認する。保守に時間をかけないため、安定した技術を選ぶ。
- Operations: エラーは記録し、異常があれば開発者に通知する。更新に失敗したら前の状態に戻せる。家族の追加・復旧・誤操作からの復元の手順は手順書にまとめる。

## Decisions

- 役割は分けず、家族は全員が同じ権限を持つ (#13)。
- 削除した動画は、30 日で完全に削除する (#14)。
- 動画の控えは取らない。誤操作からは、30 日以内なら元に戻せる (#15)。
- 動画に含まれる位置情報は、そのまま残す (#16)。
- 家族がメンバーから外れても、その人の動画は残す (#17)。
- 既存の動画の移行は、各自がアップロードして行う (#18)。
