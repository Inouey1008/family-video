# ADR-0003: 画面は SPA ではなく MPA にする (サーバーが HTML を返す)

- Status: Accepted
- Date: 2026-11-15

## Context

- クライアントは Web アプリにする ([ADR-0002](0002-client-web.md))
- 外部の部品を最小限にする (PRD の Maintenance)
- 操作の滑らかさより、セキュリティと保守性を優先する

## Decision

- 画面は MPA にする。ページごとの HTML はサーバーが組み立てて返し、ブラウザは表示と一部の差し替えだけを行う。
- フロントエンドのビルド (npm・バンドラー) は使わない。
- JS は、端末の中でしかできない処理 (アップロード・選んだ動画の保存) に限る。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| SPA (素の HTML + JS / React + Vite / Astro) | ブラウザ側で HTML を組み立てるので、JS とビルドの仕組みが増える。サーバーのテンプレートの自動エスケープで XSS を防ぐ方が確実 |

## Consequences

- 画面をサーバーが作るので、オフラインでの閲覧はできない ([ADR-0002](0002-client-web.md))。
- 使う技術は [ADR-0007](0007-htmx.md) を参照。
