# ADR-0003: フロントエンドは SPA ではなく MPA にする (サーバーが HTML を返す)

- Status: Accepted
- Date: 2026-11-15

## Context

- クライアントは Web アプリにする ([ADR-0002](0002-client-web.md))
- 外部依存を最小限にする (PRD の Maintenance)
- UX (操作の滑らかさなど) はある程度妥協してよい。セキュリティと保守性を優先する

## Decision

- 画面は MPA にする。ページごとの HTML はサーバーが組み立てて返し、ブラウザは表示と一部の差し替えだけを行う。
- フロントエンドのビルド (npm・バンドラー) は使わない。
- JS は、端末の中でしかできない処理 (アップロード・選んだ動画の保存) に限る。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| SPA (素の HTML + JS / React + Vite / Astro) | ブラウザ側で HTML を組み立てるので、JS とビルドの仕組みが増える。npm のパッケージは間接的な依存が多く、更新と脆弱性の確認が重い。React などのフレームワークも更新が盛んで、追従し続ける必要がある。サーバーのテンプレートの自動エスケープで XSS を防ぐ方が確実 |

## Consequences

- 画面をサーバーが作るので、オフラインでの閲覧はできない ([ADR-0002](0002-client-web.md))。
- 使う技術は [ADR-0007](0007-htmx.md) を参照。
