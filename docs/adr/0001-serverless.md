# ADR-0001: 常駐サーバーを持たず、サーバーレスにする

- Status: Accepted
- Date: 2026-11-15

## Context

- 費用は保存量に比例する分だけにし、固定費はほぼ 0 円にする (PRD の Goals)
- 保守に時間をかけない (PRD の Maintenance)
- 使うのは家族数人で、アクセスはまばら

## Decision

- 常に動き続けるサーバーは持たない。リクエストがあるときだけ動き、使った分だけ課金されるサービスで作る。
- OS とミドルウェアの保守は、クラウドの側に任せる。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| VPS | 使わなくても月額の固定費がかかる。OS の保守を自分で行う |
| EC2 | 動いている間ずっと課金され、アクセスがなくても固定費になる。OS のパッチを自分で当てる |
| Fargate (ECS) | タスクが動いている間ずっと課金される。ベースイメージのパッチを自分で当てる |

## Consequences

- アクセスがなければ、処理の費用はかからない。
- 1 回の処理の時間とリクエストの大きさに、サービスの制限がかかる ([ADR-0003](0003-lambda.md))。
