# ADR-0002: クライアントは Web アプリにし、サポートは iPhone の Safari だけにする

- Status: Accepted
- Date: 2026-11-15

## Context

- 家族は全員 iPhone を使う (PRD の Users)
- 保守に時間をかけない (PRD の Maintenance)

## Decision

- ネイティブアプリは作らず、Web アプリにする。
- PWA にして、ホーム画面のアイコンから全画面で開けるようにする。アプリと遜色ない使い心地になる。
- サポートは iPhone の Safari (ホーム画面からの起動を含む) だけにする。
- 動画はキャッシュしない。オフラインでの閲覧は初期リリースの範囲外にする。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| ネイティブアプリ | PWA でアプリと遜色ない使い心地にできるので、配布と更新の手間に見合わない。TestFlight は 90 日ごとの再配布、Ad Hoc は毎年の再署名、非公開配布は App Review が必要でリンクを知れば誰でも入手できる。どれも毎年の Xcode と SDK の更新が要る |

## Consequences

- iOS ではアプリを離れるとアップロードが止まる。送信済みのパートを残して再開できるようにする。それでも困るなら、アップロード専用の小さなネイティブアプリ (TestFlight) を検討する。
- Windows・Android は対象外。HEVC が再生できないため、必要になったらカメラ設定を H.264 にするか、サーバー側の変換を足す。
