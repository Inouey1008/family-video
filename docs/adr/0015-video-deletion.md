# ADR-0015: 動画は S3 のバージョニングで戻せるようにし、削除から 30 日で完全に消す

- Status: Accepted
- Date: 2026-11-15

## Context

- 削除した動画は 30 日以内なら戻せる (PRD の User Stories)
- 動画の控えは取らない (PRD の Decisions)
- 動画は S3 に置く ([ADR-0014](0014-video-storage.md))

## Decision

- S3 のバージョニングを有効にする。誤って上書き・削除しても、前のバージョンから戻せる。
- 削除から 30 日を過ぎた動画は、全バージョンを完全に削除する。バージョニングで保存料が増え続けないようにする。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| 別リージョンへの複製 | 保存料が 2 倍になる |
| バージョニングなし | 誤操作で消した動画を戻せない |

## Consequences

- アカウントの乗っ取りで動画を失うリスクは受け入れる。誤操作からは 30 日以内なら戻せる。
- 完全削除の仕組みは [設計書](../specs/data.md) を参照。
