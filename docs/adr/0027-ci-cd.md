# ADR-0027: CI/CD は GitHub Actions にし、AWS へは OIDC で認証する

- Status: Accepted
- Date: 2026-11-15

## Context

- リポジトリは GitHub の public なモノレポ ([ADR-0026](0026-repository.md))
- 長期間有効な認証情報は発行しない

## Decision

- CI/CD は GitHub Actions にする。
- AWS への認証は OIDC で行い、長期のアクセスキーは発行しない。
- 環境固有の値は、GitHub の Environment の変数とシークレットから渡す。アカウント ID を含む値はシークレットにする。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| アクセスキーをシークレットに置く | 長期の鍵が漏れると、取り消すまで使われ続ける |

## Consequences

- CI の構成とデプロイの流れは [設計書](../architecture.md) を参照。
