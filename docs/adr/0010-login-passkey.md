# ADR-0010: 招待制にし、ログインはパスキーを主にする

- Status: Accepted
- Date: 2026-11-15

## Context

- 招待した家族だけが動画を見られる (PRD の Goals)
- ログインの方法は、安全であれば何でもよい
- パスキーはフィッシングに強く、パスワードの漏えいや使い回しの心配がない
- 認証は Cognito で行う ([ADR-0009](0009-auth-cognito.md))

## Decision

- 開発者が家族を招待する。自己サインアップは無効にする。
- ログインはパスキーを主にし、予備はパスワードと TOTP にする。

## Alternatives

| 案 | 選ばなかった理由 |
|---|---|
| パスワードだけ | 漏えい・使い回し・フィッシングに弱い |
| 自己サインアップ | 家族以外も登録できてしまう |

## Consequences

- パスキーを失ったときは、予備のパスワードと TOTP でログインし、パスキーを登録し直す。手順は Runbook にまとめる ([Operations](../specs/operations.md))。
